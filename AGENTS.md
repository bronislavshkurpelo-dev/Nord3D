# Правила работы с проектом (Vanilla Stack)

## 1. Жесткие ограничения стека
- **ТОЛЬКО чистый код:** Используй исключительно нативный HTML5, CSS3 и стандартный ES6+ JavaScript.
- **ЗАПРЕЩЕНО:** Подключать любые фреймворки, библиотеки или утилиты (никаких React, jQuery, Lodash, Tailwind, Bootstrap через npm или CDN `<script>`/`<link>`).
- **Режим «Хирург»:** При исправлении бага меняй ТОЛЬКО целевую функцию, селектор или разметку. Не переписывай соседний рабочий код.

## 2. Защита от типовых багов Vanilla JS и CSS
- **Безопасный DOM:** Перед обращением к элементам всегда проверяй их существование (`const el = document.querySelector(...); if (!el) return;`).
- **События (Events):** Не вешай дублирующие `addEventListener` внутри функций перерисовки (рендера). Используй делегирование событий на родительском контейнере или очищай старые обработчики.
- **Изоляция JS:** Используй ES-модули (`<script type="module">`) или замыкания, чтобы не засорять глобальный объект `window`.
- **Чистый CSS:** Избегай `!important` и жестких фиксированных размеров (`width: 1200px`), которые ломают мобильную верстку. Используй CSS-переменные (`:root`) для цветов и отступов.

## 3. Обязательный пайплайн верификации (Self-Check)
После КАЖДОГО изменения кода ты обязан:
1. Открыть изменённую HTML-страницу во встроенном браузере Antigravity.
2. Проверить вкладку Console на отсутствие ошибок (`Uncaught TypeError`, `ReferenceError`) и вкладку Network на отсутствие `404` при загрузке скриптов/стилей/картинок.
3. Покликать все интерактивные элементы на странице (модалки, формы, кнопки, табы) минимум 2-3 раза подряд, чтобы исключить дублирование событий.
4. Проверить адаптив на ширине 375px и 1440px, приложив скриншот в Artifacts.
