# 3ДСосед — Платформа 3D-печати и 3D-сканирования в Норильске

Современная веб-платформа прямой связи заказчиков и мастеров 3D-печати и 3D-сканирования в Норильске (Талнах, Кайеркан, Оганер, Дудинка).

---

## 🚀 Быстрый запуск

### Вариант 1. Локальный запуск на Node.js (Zero Dependencies)
Сервер написан на встроенных модулях Node.js, поэтому дополнительные пакеты `node_modules` устанавливать не требуется!
```bash
node server.js
```
Откройте в браузере: **http://localhost:3000**

### Вариант 2. Запуск в Docker
```bash
docker build -t nord3d .
docker run -p 3000:3000 -v $(pwd)/data:/app/data nord3d
```

### Вариант 3. Статический хостинг (GitHub Pages / Timeweb / Beget / Reg.ru)
Просто скопируйте все файлы и папку `img/` в корневую директорию вашего хостинга (`public_html` / `www`).

## 📁 Структура проекта

* `index.html` — Главная страница платформы (промо, галерея, FAQ, интерактивный просмотр 3D-моделей).
* `order.html`, `order.js` — Оформление заказа на 3D-печать (загрузка STL/OBJ, выбор пластика, инфилла, расчет цены).
* `scan.html`, `scan.js` — Раздел заказа 3D-сканирования (фотографии детали, реверс-инжиниринг, опция печати).
* `orders.html`, `orders.js` — Лента актуальных заказов с фильтрами и подачей откликов мастеров.
* `printers.html` — Каталог мастеров Норильска с фильтрами по технологиям (FDM, SLA, 3D-скан) и материалам (включая спецпластики Nylon, Carbon, PC, ASA).
* `cabinet.html`, `cabinet.js` — Личный кабинет в стиле FunPay (живой чат, отправка фото, смена статусов заказов, анкета мастера и прайс-лист).
* `core.js` — Единое ядро: база данных, авторизация, онлайн-статусы, модалки, темы, фоновая синхронизация с API.
* `cards.js` — Генераторы карточек заказов и мастеров с динамическими бейджами.
* `styles.css` — Полная дизайн-система платформы с поддержкой светлой и тёмной темы.
* `server.js` — Легковесный Node.js бэкенд с REST API и Server-Sent Events (SSE) для мгновенного чата между устройствами.
* `data/` — Директория постоянного хранения базы данных (`db.json`).
* `.htaccess` — Готовые правила кэширования и сжатия Gzip для Apache.
* `robots.txt` — Настройки индексации для поисковых систем.

## 🛠️ API Эндпоинты бэкенда

* `GET /api/health` — Проверка статуса сервера.
* `GET /api/printers` | `POST /api/printers` — Получение и сохранение профилей мастеров.
* `GET /api/orders` | `POST /api/orders` | `PUT /api/orders/:id` — Управление заказами.
* `GET /api/chats` | `POST /api/chats/:threadKey` — Загрузка и отправка сообщений чата с фото.
* `GET /api/presence` | `POST /api/presence` — Живые онлайн-статусы пользователей.
* `GET /api/events` — Поток Server-Sent Events (SSE) для мгновенных push-обновлений.
